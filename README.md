# Ozon Mobile Hub

BUILD BRIEF — OZON MOBILES WEBSITE

You are an expert product designer, UX strategist, CRO specialist, brand designer, frontend engineer, and SEO specialist.

Build a production-quality, premium, modern, mobile-first website for Ozon Mobiles, a local smartphone retail and phone-repair business in Kerala, India.

Do NOT create a generic mobile-shop template.

The website must feel like a sophisticated modern technology brand while retaining the trust, accessibility, and friendliness of a successful local retailer.
